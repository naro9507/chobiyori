# 国税庁の公開資料との照合

確認日: 2026-11-18。専門家への依頼をリリースの前提にせず、公開資料・具体的な記帳例・自動テストで確認する。今回の対象は一般の事業所得の白色申告、事業専従者控除、開業費の手動記帳、家事按分。個別の支出の適否を自動判定する機能は追加しない。

## 根拠

- [収支内訳書（一般用）・令和5年分以降用](https://www.nta.go.jp/taxes/shiraberu/shinkoku/yoshiki/01/shinkokusho/pdf/r07/05.pdf) と [令和7年分白色申告者の決算の手引き（一般用）](https://www.nta.go.jp/taxes/shiraberu/shinkoku/tebiki/2025/pdf/034.pdf): 行番号、経費の分類、小計、専従者控除、開業費などの償却費の転記先。2026年分の手引きまで確認したという意味ではない。申告年度の様式変更は都度照合する。
- [No.2075 青色事業専従者給与と事業専従者控除](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2075.htm)（令和8年4月1日現在）: 白色の専従者給与は必要経費にしない。専従者控除は別枠で扱う。
- [No.2210 必要経費の知識](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/2210.htm)（令和8年4月1日現在）: 家事関連費は記録に基づき事業に必要な部分を区分する。支払った時期だけで経費の年度が決まるわけではない。白色で現金出納帳を先に表示しても、現金主義の所得計算へ切り替えるわけではない。
- [償却期間経過後における開業費の任意償却](https://www.nta.go.jp/law/shitsugi/shotoku/04/08.htm)（令和7年8月1日現在）: 未償却残高の範囲で任意償却が可能。支出内容・過年度に経費算入していない額を記録する。

## 手動入力の範囲

専従者控除は、同一生計・年末15歳以上・年6か月超の専従などの要件を本人の記録で確認して入力する。1人ごとに「配偶者860,000円／その他500,000円」と「控除前所得÷（専従者数＋1）」の小さい方を用い、その合計を入力する。たとえば所得1,000,000円で配偶者1人なら500,000円、配偶者とその他親族各1人なら各人の所得による上限は1,000,000÷3となる。対象者は配偶者控除・扶養控除と併用できない。人数・従事期間・他の所得との関係や申告書への氏名等の記載をアプリが自動判定・作成することはない。

保存時には負額と控除前所得を超える額を拒否する。これは明らかな入力矛盾を防ぐ最低限の検査であり、人数別の限度額や適用資格を保証する検査ではない。保存後に取引が変わって所得を超えた場合、保存値を黙って変更せず、決算画面に再計算の案内を出す。

開業費の対象費用を自動選別したり、償却額を自動決定したりはしない。開業費用の資産科目をマスタで登録し、期首残高または仕訳で残高を記録する。償却するときは「減価償却費／開業費」の手動仕訳を記録し、支出内容・償却累計・残高を保管する。固定資産の購入代金・前払費用との区別が必要であり、開業前の支出を全部経費にする案内はしない。

按分の初期割合は入力例。使用面積・使用時間などの根拠を残して変更する。切捨て・切上げ・四捨五入の選択はアプリの端数処理仕様であり、国税庁がこの方式を一律指定しているという意味ではない。

出力は転記用の金額一覧。公式用紙そのものやe-Tax送信データは生成しない。
