# DCS 会計アプリ 仕様書（ドラフト v0.1）

現行の Excel 帳簿 2 冊を読み解き、それを置き換える専用デスクトップアプリの仕様をまとめたもの。

- 対象ブック A: `DCS accounts for 2014.xlsx`（英語教室の日英併記の仕訳帳。実運用の本体）
- 対象ブック B: `平成26年 DCS仕訳帳(1). 貸借対照表.xlsx`（旧様式の仕訳帳テンプレートと、申告用の集計シート）

> 税務上の取り扱い（按分率・償却方法・控除要件など）は本書では「現行の帳簿のやり方」を写したものであり、正しさは税理士に確認すること。

## 1. スプレッドシートの解釈

### 1.1 何をしている帳簿か

個人事業（英語教室）の **複式簿記の仕訳帳** を月別シートで付け、月次・年次で科目別に集計し、最終的に **青色申告決算書（損益計算書・貸借対照表）に転記する金額** を作っている。入力はすべて「番号」で行い、名称は VLOOKUP で引く方式。

### 1.2 シート構成と役割

| ブック | シート | 役割 | アプリでの対応 |
|---|---|---|---|
| A | `No.` | 4 つのマスタ（勘定科目 1〜 / 摘要 1〜 / 生徒 1〜 + 月謝額 / 店・会社 501〜） | マスタ管理 |
| A | `Jan.`〜`Dec.` | 月別仕訳帳 + 右側に集計パネル | 仕訳入力・各種帳票 |
| A | `Fee 授業料` | 生徒別の当月入金・返金一覧 | 月謝管理 |
| A | `Total` | 科目 × 12 か月の借方/貸方、前年末残高、年末残高、青色控除前所得 | 月次推移試算表・決算 |
| A | `原紙` / `example` | 月シートの雛形・記入例 | 不要（アプリが代替） |
| A | `出力` | 仕訳帳の印刷様式（1 仕訳 = 借方行 + 貸方行） | 仕訳帳 PDF |
| B | `コード` | 科目 101〜 / 摘要 201〜 / 相手先 300〜（五十音順）/ 顧客 1〜 | マスタ管理（検索で代替） |
| B | `1月`〜`12月` / `見本` | 月別仕訳帳（A と同じ思想の旧様式） | 同上 |
| B | `貸借対照表` | 科目 × 月の借方/貸方（上期・下期・通年）＝実質は合計残高試算表 | 月次推移試算表 |
| B | `申告金額` | 青色申告決算書の損益計算書 ①〜㉜ と貸借対照表（期首/期末）への転記値 | 決算書出力 |
| B | `Sheet2` | 領収証綴りなどの背表紙ラベル | 対象外 |

### 1.3 月シートの構造（ブック A）

**仕訳入力部（A〜N 列）** — 1 行 = 借方 1 科目 : 貸方 1 科目の単一仕訳

| 列 | 内容 | 入力 |
|---|---|---|
| day | 日（月と年はシート名・ファイル名が持つ） | 手入力 |
| No. / plus / 借方 | 借方科目の番号 → 英名・和名 | 番号のみ手入力 |
| No. / minus / 貸方 | 貸方科目の番号 → 英名・和名 | 番号のみ手入力 |
| money | 金額（円） | 手入力 |
| No. / purpose | 摘要の番号 → 英名・和名 | 番号のみ手入力（任意） |
| No. / students,shop,company | 相手先の番号。1〜 は生徒、501〜 は店・会社 | 番号のみ手入力（任意） |

**右側パネル**

| パネル | ロジック | 意味 |
|---|---|---|
| 家事按分メモ（electricity / gas / water → bank, school, private） | `school = bank × 50%`, `private = bank × 50%` | 自宅兼教室の光熱費などを事業分と家事分に割る計算。結果を見て「経費」と「事業主貸」の 2 仕訳を手で入力している |
| 科目別集計（No. / plus / minus） | `SUMIF(借方No列, 科目No, 金額列)` / 貸方も同様。最下行で借方合計 = 貸方合計を目視確認 | 月次の合計試算表 |
| 現金・預金残高（シート上端） | `現金残高 = 前月残高 + 現金の借方計 − 貸方計`。前月残高は手入力 | 現金出納帳・預金残高の代わり |
| 生徒別月謝（No. / NAME / school fees / repay / receipts） | `SUMPRODUCT(相手先=生徒No × 摘要=1(月謝) × 金額)`、返金は摘要 = 11（授業料戻し）、`receipts = fees − repay` | 生徒ごとの当月入金額 |

**ブック B の月シートに追加であるもの**: 売掛金の前月残、按分率が費目ごとに違う例（50/50、80/20、30/70）、現金出納（収入・支出・累計・差）。

### 1.4 年次集計と申告（`Total` / `申告金額`）

- `Total`: 各月パネルの借方計・貸方計を科目ごとに 12 か月並べ、`年末残高 = 前年末残高 + 年間借方 − 年間貸方`。収益・費用は年間の純額。
- 固定資産（建物・建物付属設備・工具器具備品・車両運搬具・構築物・土地）は期首/期末の簿価を手で記入し、減価償却費も手計算の値を記入。
- 借入金（複数の借入先）と利子割引料、未払金の残高を追跡。
- `申告金額`: 損益計算書は 売上① → 売上原価②〜⑥ → 経費⑧〜㉛（決算書の既定科目 + 任意科目: 新聞図書費・支払手数料・販売促進費・車両費・教育訓練費）→ 計㉜ → 差引金額。貸借対照表は資産・負債の期首/期末、事業主貸・事業主借・元入金・青色申告特別控除前の所得金額で貸借を一致させている。

### 1.5 現行運用で起きている問題（アプリで解消すべき点）

読み解く中で、Excel 運用ゆえの不整合が実際に見つかった。

| # | 事象 | 原因 | アプリでの対策 |
|---|---|---|---|
| 1 | 月の借方合計と貸方合計が一致しない月がある（例: 9 月・10 月で差額 2,376 円） | 集計パネルの科目行と `No.` マスタの番号がずれている（買掛金/広告宣伝費の行に `#ERROR!`） | 複式の整合を DB 制約で保証。集計は仕訳から都度導出 |
| 2 | `Total` の普通預金の年末残高がマイナス表示 | 前年末残高を入れる列を間違えている | 期首残高は専用画面で入力し、繰越は自動 |
| 3 | 生徒別パネルの和名が別人の名前にずれている／旧ブックの顧客名が混入 | 雛形コピー時の貼り付けずれ | 名称は常にマスタから表示 |
| 4 | `#REF!`、外部ブック参照 `[1]コード!`、行ごとにばらばらな VLOOKUP 範囲 | シート複製の積み重ね | 数式を持たない |
| 5 | 行数上限（SUMIF は 85 行、月謝集計は 52 行まで）を超えると黙って集計から漏れる | 固定範囲の数式 | 上限なし |
| 6 | 前月残高・売掛残・繰越金を毎月手で転記 | シートが月ごとに独立 | 連続した帳簿として自動繰越 |
| 7 | 日付が「日」だけで、入力順もばらばら | シート構造 | 完全な日付を保持し日付順に表示 |
| 8 | 按分は電卓代わりのメモで、2 本の仕訳は手入力 | 仕組みがない | 按分ルールから自動で 2 行に分割 |
| 9 | 月謝の「誰が未納か」は一覧から目で探す | 入金額しか出ていない | 予定額（月謝額マスタ）と突き合わせて未入金を表示 |
| 10 | 見出しの年月・和暦が古いまま（`Junuary , 2007`、平成 20 年 等） | 手で書き換える運用 | 会計年度から自動表示 |

## 2. 製品コンセプト

**「番号で打てる、いまの帳簿のまま、間違えようがない仕訳帳」**

- 現行の入力リズム（日 → 借方 No → 貸方 No → 金額 → 摘要 No → 相手先 No）をそのままキーボードだけで再現する。
- 集計・繰越・按分・月謝集計・決算書の数字はすべて仕訳から自動導出し、手転記をなくす。
- 日本語 / 英語をいつでも切り替えられる（現行帳簿が全項目日英併記のため必須要件）。
- 完全オフライン・ローカル保存・暗号化。

### スコープ

| 区分 | 内容 |
|---|---|
| v1 に含む | マスタ、仕訳入力、家事按分、定型仕訳、月謝管理、仕訳帳/元帳/出納帳/試算表、期首残高と年度繰越、固定資産台帳と減価償却、青色申告決算書の金額一覧、Excel 取込、CSV/PDF 出力、バックアップ/復元 |
| v1 に含まない | e-Tax 直接送信、確定申告書 B 本体の作成（所得控除など）、消費税申告、銀行/カード明細の自動連携、給与計算・年末調整、複数事業・複数ユーザー |

**F1-4 取引先（shop, company）** — 番号（現行は 501〜）、英名・和名、既定の摘要。借入先（金融機関）もここに含む。

- 現行は相手先番号 1 列に生徒と店を混在させている。入力欄は 1 つのまま、番号帯または名前検索でどちらにも解決できるようにする。

### F2. 仕訳入力

**F2-1 高速入力グリッド（主画面）**

- 月単位の表。列は現行と同順: 日 / 借方 / 貸方 / 金額 / 摘要 / 相手先 / メモ。
- 各コード欄は「番号を打って Enter」でも「名前の一部（英・和・かな）で絞り込み」でも入力可。確定すると英名・和名を表示。
- Enter / Tab で次の欄、行末で次の行を自動追加。日・借方・貸方は直前行の値を既定にできる（同じ日の現金払いが続く運用に合わせる）。
- 入力順は保持しつつ、表示は日付順 / 入力順を切替。
- 画面下に当月の借方計・貸方計、現金残高、普通預金残高を常時表示。
- バリデーション: 日付は当該会計年度内、金額は 1 円以上の整数、借方 ≠ 貸方、マスタに存在する番号のみ。

**F2-2 家事按分（現行の electricity / gas / water パネルの置き換え）**

- 按分ルール = 名前 + 事業割合（%）+ 端数処理（切り捨て / 四捨五入 / 切り上げ、端数は家事側に寄せる）。初期値は現行の 50%。
- 按分ルール付きの摘要で支払額（例: 引落額 20,486 円）を入れると、
  `水道光熱費 / 普通預金 10,243` と `事業主貸 / 普通預金 10,243` の 2 明細を 1 つの取引として自動生成する。
- 割合は取引ごとに上書き可。年の途中で率を変えても過去の仕訳は変わらない。

**F2-3 定型仕訳・毎月の繰り返し**

- よく使う仕訳をテンプレート登録（例: 借入返済 = 元金「借入金 / 普通預金」+ 利息「利子割引料 / 普通預金」+ 相手先）。
- 「毎月 N 日」の繰り返し設定を持てる。月を開いたとき未登録分を候補として提示し、金額を確認・修正して確定する（自動で勝手に記帳はしない）。
- 前月の仕訳を選んでコピーする機能。

**F2-4 取引の単位**

- 画面上は現行どおり 1 行 = 借方 1 : 貸方 1。内部では「取引（ヘッダ）+ 明細行」で持ち、按分や返済のように関連する複数行を 1 取引としてまとめる。v1 では複合仕訳（N:M）の自由入力は提供しない。

**F2-5 修正・削除・締め**

- 修正・削除は可能だが変更履歴を残す（誰が/いつ/何を。電子帳簿の訂正削除履歴に相当）。
- 月締め・年締めでロック。ロック解除は明示操作 + 履歴記録。

### F3. 月謝管理（`Fee 授業料` と生徒別パネルの置き換え）

- **入金登録**: 生徒を選ぶと月謝額が金額に入り、`現金 or 普通預金 / 売上`、摘要「月謝」の仕訳になる。対象月（何月分か）を持てる（前払い・まとめ払い対応）。
- **返金**: 摘要「授業料戻し」で `売上 / 現金` を登録。生徒別の受取額から差し引く。
- **月次一覧**: 生徒 × （予定額 / 入金 / 返金 / 差引受取 / 状態）。状態は 入金済・一部・未入金・対象外（休会）。
- **年間マトリクス**: 生徒 × 12 か月の受取額。未入金セルを強調。
- **現金売上の一括計上にも対応**: 現行は月末に `現金 / 売上` をまとめて 1 行で計上している月がある。生徒未指定の売上も許容し、月謝一覧では「生徒未割当の入金」として別枠表示する。
- 領収書（PDF）の発行は v1.1 以降の候補。

### F4. 帳票・照会

| 帳票 | 内容 | 現行の対応物 |
|---|---|---|
| 仕訳帳 | 日付順。印刷様式は現行 `出力` と同じ 1 仕訳 2 行（借方行・貸方行、摘要、相手先） | `出力` |
| 総勘定元帳 | 科目別の明細と残高 | なし（新規） |
| 現金出納帳 / 預金出納帳 | 入金・出金・残高。実際の現金・通帳残高との照合欄 | 月シート上端の残高、B の収入/支出/累計 |
| 合計残高試算表（月次） | 科目別の借方計・貸方計・残高、貸借一致チェック | 月シートの集計パネル |
| 月次推移表（年次） | 科目 × 12 か月 + 前年末 + 年末 | `Total`、B の `貸借対照表` |
| 相手先別集計 | 取引先別・摘要別の支出 | なし（新規） |

- すべて期間指定、CSV / PDF 出力可。金額クリックで該当仕訳へドリルダウン。

### F5. 決算

**F5-1 期首残高** — 初年度のみ手入力（現金、預金、固定資産、借入金、未払金、元入金 ほか）。貸借が一致しないと確定できない。

**F5-2 固定資産台帳と減価償却**

- 資産ごとに: 名称、科目、取得日、取得価額、耐用年数、償却方法（定額法が既定）、事業専用割合、期首簿価。
- 年次で償却費を計算し、`減価償却費 / 各資産科目` の決算仕訳を生成（確認後に確定）。事業専用割合を掛けた額を経費に、残りを事業主貸に。
- 土地は非償却。既存資産は現行の期首簿価から開始できる。

**F5-3 決算整理** — 未払金・売掛金・前払金の計上、期末棚卸（該当時）、按分の年次見直しを手動仕訳で登録できるチェックリスト。

**F5-4 青色申告決算書の金額一覧（`申告金額` の置き換え）**

- 損益計算書: ①売上 → ②〜⑥売上原価 → ⑦差引金額 → ⑧〜㉛経費 → ㉜経費計 → 差引金額 → 青色申告特別控除前の所得金額。
- 貸借対照表: 資産・負債の期首 / 期末、事業主貸、事業主借、元入金、青色申告特別控除前の所得金額。**資産合計 = 負債・資本合計** を検証。
- 月別売上（仕入）金額、減価償却費の計算、地代家賃・利子割引料の内訳など、決算書 2〜3 ページ目に必要な値。
- 出力は「転記用の金額一覧（画面 + PDF）」。国税庁様式そのものへの印字や e-Tax データ出力は将来課題。

**F5-5 年度繰越** — 資産・負債の期末残高を翌期首へ。`翌期首元入金 = 期末元入金 + 青色控除前所得 + 事業主借 − 事業主貸`。マスタと定型仕訳は引き継ぐ。

### F6. データ取込・出力

- **Excel 取込（移行用）**: 現行様式のブックを選ぶと、`No.` シート → 4 マスタ、月シート → 仕訳、として読み込む。取込前にプレビューと検証結果（未定義の番号、金額なしの行、貸借不一致、重複）を表示。現行ブックには雛形の空行・番号だけの行が多数あるため、金額のない行は無視する。
- **CSV 出力**: 仕訳、各帳票、マスタ。
- **PDF 出力**: 仕訳帳、元帳、試算表、決算書金額一覧。
- **バックアップ / 復元**: 暗号化した単一ファイルに書き出し・読み込み。終了時の自動バックアップ（世代保持）。

### F7. 設定

- 事業者情報（屋号、氏名、住所）、会計年度（暦年固定）、表示言語（日/英/併記）、和暦/西暦表示、データ保存先、起動時パスワード。

## 5. データモデル（SQLite）

金額はすべて円単位の整数。

| テーブル | 主な列 |
|---|---|
| `fiscal_years` | year, status（open/closed）, closed_at |
| `accounts` | id, code（現行 No）, name_ja, name_en, type（asset/liability/equity/revenue/expense）, statement_line（決算書の行）, is_system, is_active, sort |
| `purposes` | id, code, name_ja, name_en, default_debit_account_id, default_credit_account_id, allocation_rule_id, is_active |
| `partners` | id, code, kind（student/vendor）, name_ja, name_en, is_active, memo |
| `students` | partner_id, monthly_fee, status, joined_on, left_on |
| `allocation_rules` | id, name, business_percent, rounding |
| `transactions` | id, fiscal_year, date, kind（normal/allocation/template/depreciation/opening/closing）, memo, source（manual/import）, created_at, updated_at |
| `journal_lines` | id, transaction_id, line_no, debit_account_id, credit_account_id, amount, purpose_id, partner_id, fee_month, memo |
| `templates` / `template_lines` | 定型仕訳。recurrence（none/monthly）, day_of_month |
| `opening_balances` | fiscal_year, account_id, amount |
| `fixed_assets` | id, account_id, name, acquired_on, cost, useful_life, method, business_percent, opening_book_value, disposed_on |
| `month_locks` | fiscal_year, month, locked_at |
| `audit_logs` | id, entity, entity_id, action, before_json, after_json, at |
| `settings` | key, value（既存） |

- 既存の `incomes` / `expenses` テーブルは `journal_lines` に置き換える（収入 = 貸方が収益科目の行、支出 = 借方が費用科目の行、というビューで代替）。
- 集計値（月次合計・残高）は保存せず、常に `journal_lines` + `opening_balances` から計算する。

### 計算ルール

| 値 | 定義 |
|---|---|
| 科目の月次借方計 / 貸方計 | 当月の `journal_lines` を `debit_account_id` / `credit_account_id` で合計（現行 SUMIF と同じ） |
| 資産の残高 | 期首 + 借方計 − 貸方計 |
| 負債・資本の残高 | 期首 + 貸方計 − 借方計 |
| 収益 / 費用の年間額 | 貸方計 − 借方計 / 借方計 − 貸方計 |
| 青色控除前所得 | 収益計 − 売上原価 − 経費計 |
| 生徒の受取額 | 摘要 = 月謝 の合計 − 摘要 = 授業料戻し の合計（現行 SUMPRODUCT と同じ） |
| 按分 | 事業分 = round(支払額 × 事業割合)、家事分 = 支払額 − 事業分 |

## 6. 非機能要件

- **オフライン**: ネットワーク接続なしで全機能が動く。外部送信なし（自動更新を使う場合のみ例外で、無効化できること）。
- **データ保護**: DB は SQLCipher で暗号化（既存依存を利用）。生徒名などの個人情報を含むため、バックアップファイルも暗号化。ログに個人名・金額を出さない。
- **整合性**: 仕訳の登録・按分・決算仕訳の生成はトランザクションで実行。貸借一致を自動テストで保証。
- **性能**: 年 2,000 仕訳程度（現行は月 60 行前後）で入力・集計とも体感待ちなし。
- **i18n**: 全ラベル・帳票見出しを日英対応。マスタ名称は日英 2 項目を保持。
- **対応 OS**: `docs/PLATFORM_SUPPORT.md` に従う。
- **テスト**: 計算ロジック（集計・按分・償却・繰越）は Vitest で単体テスト。現行ブックの 2014 年データを取り込み、`Total` の値と一致することを受け入れテストにする（個人名は匿名化したフィクスチャを使用）。

## 9. 確認したい事項

1. **対象事業**: アプリの対象は英語教室（ブック A）のみでよいか。ブック B の月シートにあるエステサロン風の科目・顧客データは旧雛形の名残と解釈した。
2. **言語**: 画面は日英併記か、切替式か。入力する人の主言語はどちらか。
3. **月謝の計上**: 生徒ごとに入金を記録したいか、現行のように現金分は月末一括計上でもよいか。未入金管理はどこまで必要か。
4. **家事按分**: 対象費目と割合（電気・ガス・水道・電話・ネット・車両 など）。現行は 50% だが費目ごとに決めたい。
5. **固定資産**: 現在の資産一覧（取得日・取得価額・耐用年数）が分かる資料はあるか。建物は自宅兼事務所として事業割合で償却しているか。
6. **借入金**: 借入先ごとに残高・返済予定を管理したいか（現行は 2 つの借入先に毎月元金 + 利息を返済）。
7. **消費税・インボイス**: 免税事業者の前提でよいか。課税事業者なら税区分の管理が必要になり、仕様が大きく増える。
8. **申告方法**: 決算書は金額一覧を見て手書き/国税庁サイトに転記する想定でよいか。e-Tax 用データ出力や 65 万円控除の要件（電子帳簿保存 or e-Tax）対応まで必要か。
9. **過去データ**: 何年分を取り込むか。2014 年以降のブックも同じ様式か。
10. **利用環境**: 使う PC の OS、利用者は 1 人か。
