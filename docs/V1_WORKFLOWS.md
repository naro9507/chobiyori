# フェーズ 11 後の v1 補完

## 今回の実装

- F10 のヘルプ画面に、はじめての方へ・目的別の案内・入力例・用語集・キーボード操作を同梱した。日本語・英語に対応し、用語は読みがなでも検索できる。入力例は科目を引き継いでかんたん入力を開く。画面上部の案内リンクと F1 は、その画面名でヘルプを探す。
- Ctrl+K / ⌘K でコマンドパレットを開く。画面の移動、取引・請求書の新規作成、ヘルプ検索に対応し、上下キー・Enter・Esc で操作できる。
- 初期設定は事業者・申告区分・年度・口座・期首残高・機能の 6 手順。現金・預金・カード・電子マネーを登録し、その他の資産や借入金の残高も入力できる。元入金は Rust で資産と負債の差額から求め、全体を 1 トランザクションで保存する。残高は決算の期首残高で確認して確定する。開業 1 年目には開業費・元入金の案内を出す。
- 機能の設定は帳簿の `settings` に保存する。既存の帳簿では全機能を有効として扱う。在庫は決算の棚卸タブ、売掛・買掛は請求書メニューと取引先別帳簿、定期売上は売上管理・繰り返し入力・ホームの候補、家事按分は按分ルールのタブと入力欄の表示に反映する。非表示にしてもデータは削除しない。設定から再び有効にできる。
- マスタの「摘要」で、コード・和名・英名・かな・既定の科目・税区分・取引先・按分ルールを管理する。取引入力では摘要を選んで仕訳の内容を確認し、日付と金額を入力して記録する。使用中の摘要は削除できず、無効化する。按分の端数処理、免税年度、月締め・年締めは既存の会計処理を使う。
- 白色の年度は専用の収支内訳書（一般用）の行定義を使う。事業専従者控除は確認済みの金額を入力して保存し、所得金額・申告案内・CSV/PDF に反映する。青色の専従者給与は白色では経費から外し、確認を促す。帳簿は現金・預金出納帳、経費帳、売上帳を先に並べ、現金・預金出納帳を初期表示する。売上帳は CSV/PDF でも保存できる。

## 保存と互換性

既存の `purposes`・`opening_balances`・`settings` を利用し、スキーマの変更はない。古い初期設定の入力も、新しい項目を省略した場合は口座・残高なし、全機能有効として受け付ける。口座ごとの期首残高は勘定科目単位で持つため、新しく登録する預金・カード・電子マネーはそれぞれ独立した勘定科目として保存する。

事業専従者控除の適用条件や上限、開業費の対象などの税務判断は自動化していない。国税庁の公開資料と手元の記録で確認する。照合記録と自動検証の範囲は [TAX_VALIDATION.md](./TAX_VALIDATION.md) を参照。収支内訳書の表示・出力は転記用の金額一覧であり、国税庁の用紙そのものの PDF は作らない。

## 検証

通常の確認は `pnpm test`、`pnpm typecheck`、`pnpm check`、`pnpm build:web`、`pnpm test:rust`、`pnpm lint:rust`、`pnpm format:rust` で行う。

今回の環境では Tauri が必要とする GTK/WebKit の開発ライブラリがなく、通常の `cargo test` は起動前のビルドで停止した。システムライブラリの追加も自動承認レビューを完了できなかったため実行していない。代わりに、リポジトリの会計・DB・取込・出力・メール・レシートの Rust ソースを直接参照する一時的な Cargo 構成でテストと Clippy を実行した。Tauri のコマンド登録とデスクトップの実動作は、この代替検証の対象に含まない。

コミット前の再検証では、画面テスト 107 件、上記の一時的な構成の Rust テスト 283 件、Biome・TypeScript・Web ビルド・rustfmt・Clippy が通った。システム依存の追加は `sudo` がないため実行できず、通常の Tauri 構成の検査は GitHub CI での確認が必要。


## ヘルプの続き（PR #23 後）

用語のそばの「?」から、ふりがなと説明を読める。マウスを重ねる、Tab で選ぶ、クリックする操作に対応し、Esc で閉じられる。入力欄のラベルとは分けているため、入力欄の名前と操作は変えない。

画面の説明は初回案内として表示し、閉じた画面を端末の `dcs-help-preferences` に記憶する。画面を移動したり再読み込みしたりしても、閉じた案内は再表示しない。閉じても右上のヘルプと F1 は引き続き使える。

ヘルプとコマンドパレットは、帳簿に保存した業種テンプレートと機能設定を共通で参照する。学校の教材・月謝、サービス業の参考書、小売・飲食の仕入、売掛金の回収の入力例を追加した。使わない機能の例と画面の案内は非表示にする。入力に必要な科目・口座が無効、未登録、または口座として使えない場合は説明だけを表示して入力ボタンを無効にする。業種の記録がない古い帳簿とブラウザだけの表示では汎用の案内を使う。

パレットや F1 で選んだ説明は、本文のキーワード検索とは別に記事を指定して開く。たとえばパレットから「借方」を選ぶと、本文に「借方」を含む入力例より先に、借方そのものの説明を表示する。検索欄を編集すれば全体の検索に戻る。

共有 Chromium で、読みがな検索、Ctrl+K と Enter による説明の表示、案内を閉じた状態の再読み込み、用語説明のクリック・Tab・Esc を確認した。Tauri のネイティブ画面は、この環境に GTK/WebKit の開発ライブラリがないため起動していない。DB の接続を含む業種の保存・読み出しは Rust のテストで検証する。公開資料との照合は [TAX_VALIDATION.md](./TAX_VALIDATION.md) に記録する。

この差分では画面テスト 116 件と、一時的な構成の Rust テスト 284 件が成功した。型チェック・Biome・Web ビルド・rustfmt・Clippy も成功。
